1. 오늘의 질문 답변 저장

codex/qa-answercodex/qa-calendar-answer서버 실연동 보류
원인
Home은 답변을 화면 상태에만 복사하고 즉시 성공 토스트를 띄웠습니다. Calendar 기록 버튼은 빈 클로저였습니다.
해결
회원 Home과 Calendar는 날짜별 질문·기존 답변을 읽고, POST /api/v2/member-quotes/{dailyQuoteSeq}/answer 성공 후에만 완료 상태로 전환합니다. 실패하면 초안을 유지합니다. 두 화면의 회원 데이터를 저장 뒤 재조회하도록 무효화합니다. 비회원은 앱 세션 안에서 날짜별 답변을 복원합니다. Home 성공 토스트를 Figma에 맞추고 키보드를 내립니다.
검증
Home과 Calendar의 reducer·모델·앱 캐시 테스트, 저장 UI 테스트 통과. 영상 2개는 저장 완료 상태 fixture이며, 실제 회원 API 왕복은 확인하지 않았습니다.
원인·해결 문서Figma QA 기록

2. 이미지 업로드 2MB 제한

codex/qa-image-size서버 실연동 보류
원인
PhotosPicker 원본을 디코딩·변환하지 않고 .jpg 파일명과 image/jpeg 요청으로 업로드했습니다.
해결
방향을 반영해 JPEG로 변환하고 품질·해상도를 조정해 2,000,000바이트 이하로 만든 뒤 업로드합니다. 임시 파일을 요청 종료 시 정리합니다.
검증
큰 PNG의 변환·용량 상한과 잘못된 이미지 데이터 거부 테스트 통과. QA의 “2MB”를 보수적으로 2,000,000바이트로 해석했습니다.
실제 사진 선택 → 압축 → 서버 업로드 영상은 회원 테스트 환경에서 아직 확보하지 못했습니다. 이 변경의 직접 증거는 바이트 단위 자동 테스트입니다.
원인·해결 문서검증 기록

5. 응답 지연

codex/qa-latencycodex/qa-weekly-cache실측 보류
원인
Home의 날짜 이동마다 일간 조회가 반복되었습니다. 공통 로딩은 여러 작업이 모두 끝날 때까지 유지되므로 표시 시간만으로 서버 지연을 단정할 수 없습니다.
해결
Debug API 요청의 전송·디코딩·총 시간을 분리해 기록합니다. 회원 Home은 v2 주간 응답을 재사용하고, 다른 7일 창에 들어갈 때만 1회 조회합니다. 비회원은 기존 v1 일간 경로를 유지합니다.
검증
같은 창에서 날짜 6회 이동 시 피드 요청이 코드 경로상 6→0회, 경계 진입 1회, 다시 캐시된 창 진입 0회인 테스트를 통과했습니다. QA 네트워크와 서버 처리 시간은 확보되지 않아 체감 속도 수치를 제시하지 않습니다.
원인·해결 문서주간 캐시 QA 기록
문서와 영상 경로는 이 HTML 파일을 기준으로 한 상대 경로입니다. 소스와 영상 파일을 함께 보관해야 재생됩니다. Notion QA 원문 링크는 이슈별 원인·해결 문서에 있습니다.
