## Validation rounds

아래는 구현 중간 기록과 최종 확인 결과다. 기능 검증과 전체 화면 시각 수용을 구분한다.

- RED: 기존 달력 선택 하트 접근성 값이 비어 있고 등록 이미지 버튼이 계속 “이미지 등록”인 것을 UI 테스트로 확인했다.
- RED: 온보딩 테스트에서 첫 로그인 후 가이드 대신 홈으로 바로 이동하고 완료 기록이 없는 것을 확인했다.
- GoogleSignIn 10.1.0 패키지 해석 및 Swift 컴파일 통과. 공식 SDK 취소 enum은 `GIDSignInError.canceled`.
- 2차 테스트: Google 인증 성공/취소 및 세션 영속성 통과, Home/Calendar Swift Testing 47건 통과. 온보딩 테스트는 비동기 receive 대기를 누락하여 수정했다.
- 시뮬레이터 UI runner가 Busy 오류로 실패해 기기를 재시작했다. 재실행 결과와 실제 캡처는 아래에 추가한다.
- 실제 Google OAuth/서버 계정 연동은 미검증. 저장 팝업은 Notion 기획·댓글 및 후속 사용자 결정으로 분기를 확정했다. 기존 `연속 2일 이상` 제안은 폐기했다. [Home 확정 정책](../screens/2_home.md)을 구현에 반영했다.

### Round 1 — 컴포넌트 및 전체 화면 캡처

- Runtime 원본: `assets/ios-qa-2026-10-25/round-1/`의 `login-dark-full-frame.png`, `home-image-registered-full-frame.png`, `calendar-copy-full-frame.png`.
- 비교 산출물: 동일 폴더 `login-dark-comparison.png`, `home-image-comparison.png`, `calendar-comparison.png`. 왼쪽 Figma 원본 전체, 오른쪽 런타임 원본 전체를 1170×2532에서 390×844로 1/3 축소. crop 없음.
- 이미지 버튼: 실제 fixture 이미지(빨간 테스트 이미지)의 28pt 썸네일과 “이미지 보기” 전환 확인. Figma의 샘플 사진을 앱에 넣지 않았다.
- 달력: 선택 날짜의 채워진 하트, 24pt 체크 슬롯/50pt 복사 토스트 표시 확인. 탭 시 XCTest의 자동 스크롤 때문에 상단 상태바/헤더는 캡처에서 화면 밖으로 이동한 상태다. 전체 화면 비교 최종 수용 증거로 삼지 않는다.
- 로그인: PNG 1×에서 로고/Google 아이콘이 흐려져 원본 노드 SVG로 교체. Figma의 본문 48pt 영역/중앙 정렬, Google 배경 `#EEEEEF` 보정. 비회원 버튼은 기존 사용자 지시에 따라 제외.
- 기존 프로젝트에는 Pretendard/Gangwon 폰트 파일·등록이 없으며, `Font.custom`은 시스템 폰트로 대체될 수 있다. 전역 폰트 등록은 요청 범위 밖 화면까지 변경하므로 이번 변경에 포함하지 않는다. 원본 로고는 텍스트까지 path인 SVG로 해결했다. 본문·버튼 폰트 및 기존 레이아웃 차이는 최종 Figma 수용의 남은 차이다.
- 3차 실행: 온보딩 첫 로그인/재로그인 및 늦은 응답 차단, Calendar reducer 15건, 복사/하트/이미지 UI 통과. Dark 로그인 색상 테스트가 UI runner의 `UIScreen` 폭으로 좌표를 환산해 실패하여 실제 앱 프레임 폭을 사용하도록 수정.
- 최종 UI 수용: **Blocked**. Figma360pt 대비 런타임390pt 및 기존 폰트/레이아웃 차이. 기능 테스트 통과를 Figma 전체 화면 Pass로 취급하지 않는다.
