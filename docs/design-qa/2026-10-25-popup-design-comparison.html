04 · 이번에 확정한 동작

오늘 문장 완료 → ‘연속 필사 완료!’첫날 완료도 포함합니다. 오늘을 이미 완료한 상태에서 과거 문장을 완료하면 ‘필사 완료!’를 표시합니다.
재저장 → 팝업 재노출완료한 문장을 다시 저장해도 결과 팝업을 보여줍니다. 완료 상태가 바뀌었는지만으로 재노출을 막지 않습니다.
‘확인’ → 홈 화면완료 팝업의 확인 버튼을 누르면 홈으로 이동합니다.
‘취소’ → 팝업만 닫기미완료 팝업의 취소 버튼은 입력 화면을 유지하며 팝업만 제거합니다.

2026-10-25 사용자 답변을 반영한 정책 기록입니다. 이번 보고서 작성에서 앱 동작을 변경하지는 않았습니다.

05 · 남은 디자인 선택

A. 기존 일반 완료 사용

왼쪽 ‘필사 완료!’ 원본을 그대로 적용합니다. 원본은 확보되어 있습니다.

다른 리뉴얼 팝업과 이미지 크기·높이·라이트 버튼 색상이 달라집니다. 사용 여부는 미결정입니다.

B. 리뉴얼 일반 완료 지정

일반 완료용 리뉴얼 Figma 프레임을 지정하거나, 사용할 캐릭터와 변경 범위를 승인합니다.

스타일을 통일할 수 있습니다. 어떤 캐릭터를 사용할지는 확인된 원본만으로 정할 수 없습니다.

결정 완료 · 2026-10-25
사용자가 “리뉴얼 팝업 사용”을 확정했습니다. 리뉴얼 안내 팝업의 카드·캐릭터·버튼을 재사용하고 제목을 “필사 완료!”로 적용합니다. 아래 원본 비교는 결정 당시의 근거로 보존합니다.
