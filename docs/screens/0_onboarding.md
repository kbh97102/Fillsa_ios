# [랜딩 페이지] `0.onboarding`

## 기능

- 앱 최초 다운로드 시 시스템 알림 허용 OS 팝업 노출
- 권한 허용 여부와 별개로 앱 시작 시 APNs 원격 알림 등록을 요청하고, 허용된 기기에서는 FCM 원격 알림을 수신할 준비를 한다.
- Firebase 초기화와 APNs/FCM 토큰 연결은 SwiftUI 앱 생명주기에 연결한 `UIApplicationDelegate`가 담당한다.

## iOS 회원 전용 시작 경로 — 구현 완료 (2026-10-09)

스플래시는 기존 권한 확인과 애니메이션이 끝난 뒤 **첫 실행 여부와 로그인 여부를 모두 확인**한다. 첫 실행 기록은 로그인 상태를 대신하지 않으며, Home 진입은 로그인 여부로 결정한다.

| 첫 실행 | 로그인 상태 | 이동 화면 |
|---|---|---|
| 예 | 로그아웃 | 로그인 화면 |
| 아니요 | 로그아웃 | 로그인 화면 |
| 예 | 로그인 | Home |
| 아니요 | 로그인 | Home |

- 로그인 상태 조회에 실패하면 로그인 화면으로 이동한다. 확인되지 않은 세션으로 Home을 열지 않는다.
- 첫 실행 여부는 기록하지만 현재 로그인 화면의 표시 상태를 바꾸지 않는다. 사용자가 로그인하지 않은 채 앱을 종료하고 다시 열어도 Home으로 이동하지 않는다.
- 로그인 성공 후에는 기존처럼 Home으로 이동한다.
- `SplashFeatureTests`에서 위 네 조합, 로그인 상태 조회 실패, 중복 완료 이벤트를 확인했다. 검증 기록은 [회원 전용 시작 및 로그아웃 QA](1_login_member_only_qa_2026-10-09.md)에 있다.
- 로그인 화면의 표시 상태와 로그아웃 경로는 [로그인 화면 계획](1_login.md)을 따른다.
