# [알림] `5-2.inform`

## 오늘의 필사 알림 토글

- 오전 9시에 발송
- 설정값은 기기별 로컬에 저장 (SharedPreferences / DataStore)
- iOS는 `UserNotifications`의 반복 로컬 알림으로 예약한다.
- iOS에서 토글 ON 시 알림 권한 상태를 확인하고, 미결정이면 시스템 권한 팝업을 요청한다.
- iOS에서 토글 OFF 시 예약된 오늘의 필사 알림을 취소한다.

### 푸시 알림 형식

| 항목 | 내용 |
|------|------|
| 타이틀 | 오늘의 필사 문장 |
| 내용 | {오늘 명언} - {저자} |

### iOS 구현 메모

- Android는 `DailyNotificationWorker` 실행 시점에 오늘 명언 API를 호출해 알림 내용을 구성한다.
- iOS의 단순 반복 로컬 알림은 트리거 실행 시점에 네트워크 API를 호출하지 않는다.
- 현재 iOS 구현은 매일 오전 9시에 고정 문구 `"오늘의 필사 문장을 확인해보세요."`를 표시한다.
- 오늘 명언 본문을 Android처럼 매일 동적으로 넣으려면 `BGTaskScheduler` 기반 백그라운드 갱신 또는 푸시 서버 방식이 추가로 필요하다.
- Firebase Cloud Messaging SDK와 APNs 등록 기반은 추가한다. FCM 토큰을 Fiilsa 서버에 등록하는 API는 현재 Android/iOS 코드와 문서에서 확인되지 않아 서버 전송은 API 계약 확정 후 연결한다.
- 서버 푸시로 전환하기 전까지 알림 토글은 기존 로컬 반복 알림을 예약/취소한다.

## API

### 회원 탈퇴

```
DELETE /api/v1/auth/withdraw
```

**Response: `Int`**

- 인증 토큰 필요
- 탈퇴 후 로컬 토큰, 사용자명, 프로필 이미지 정보를 삭제하고 Home으로 이동
