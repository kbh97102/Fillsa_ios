# 마이페이지 회원탈퇴 노출 변경 설계

## 목표

계정 삭제의 진입점을 로그인한 회원의 마이페이지에 직접 노출한다. Apple App Review Guideline 5.1.1(v)에 맞춰 심사자가 로그인 후 쉽게 발견하고, 기존 서버 삭제와 세션 정리 흐름을 완료할 수 있게 한다.

## 기준

- Figma: `5. my page_login` (node `2929:11031`)
- 기존 iOS 탈퇴 동작: `AlertFeature`의 `DELETE /api/v1/auth/withdraw` 호출, 세션 삭제, 홈 탭 복귀
- Android 원본은 알림 화면에 탈퇴를 두지만, 이번 Figma 변경을 사용자의 명시적 승인으로 iOS에 반영한다.
- 새 화면, 새 API, 새 문구, 새 확인 단계는 만들지 않는다.

## 화면 및 노출 규칙

### 로그인 회원

마이페이지의 하단 보조 메뉴는 아래 순서로 320pt 너비의 고정 행을 표시한다.

1. `로그아웃`: 50pt 높이, 굵은 16pt 텍스트, 우측 화살표, 기존 로그아웃 동작.
2. `버전`: 50pt 높이, 좌측 굵은 16pt `버전`, 우측 일반 16pt 앱 표시 버전. 현재 `CFBundleShortVersionString` 값을 사용한다.
3. `회원탈퇴`: 50pt 높이, 좌측 일반 16pt, 회색 `#616161`, 우측 화살표 없음.

상단 회원 카드와 공지사항·알림·테마 카드의 구성은 Figma와 현재 iOS 구조를 유지한다. `회원탈퇴` 탭 영역은 행 전체이며, 장애가 없는 동안에만 탭할 수 있다.

### 비회원

`회원탈퇴`와 `로그아웃`은 보이지 않는다. 버전 행만 남는다. 계정이 없는 사용자는 계정 삭제를 시작할 수 없다.

### 알림 화면

알림 토글만 남긴다. 회원탈퇴 행과 탈퇴 확인 모달은 제거한다.

## 동작과 상태

`MyPageFeature`가 회원탈퇴 UI와 효과를 소유한다. 이는 Android의 MVI에서 마이페이지 ViewModel이 마이페이지의 사용자 이벤트·로딩 상태를 직접 관리하는 것과 같다.

마이페이지 상태에 다음을 둔다.

- `isProcessing`: 삭제 요청 중 중복 탭을 막는다.
- `isResignDialogPresented`: 기존 문구의 확인 모달 표시 여부.
- `toastMessage`: 실패 시 기존 `탈퇴 처리에 실패했습니다.` 문구를 표시한다.

이벤트 흐름은 다음과 같다.

1. 로그인 회원이 `회원탈퇴`를 누른다.
2. 기존 확인 문구 `탈퇴하시겠습니까?` / `탈퇴 후에는 작성하신 필사 정보를 되돌릴 수 없습니다.` 와 `탈퇴하기`, `취소` 버튼을 표시한다.
3. `탈퇴하기` 확인 시 `DELETE /api/v1/auth/withdraw`를 호출한다.
4. 성공 시 Keychain/UserDefaults 기반 로컬 세션·사용자 정보를 삭제하고, 앱 루트가 홈 탭의 비회원 상태로 돌아간다.
5. 실패 시 로그인 상태와 마이페이지를 유지하고 실패 토스트를 표시한다.
6. 취소 또는 바깥 영역 탭은 요청 없이 모달만 닫는다.

확인 모달의 문구·버튼 순서·삭제 API·성공 후 이동은 기존 구현을 재사용한다.

## 아키텍처 경계

- `MyPageBottomButtonSection`: Figma 하단 행의 표시와 클릭 콜백만 담당한다.
- `MyPageFeature`: 탈퇴 확인 상태, 삭제 effect, 실패 상태, 성공 후 앱 루트에 전달할 delegate 이벤트를 담당한다.
- `MyPageView`: 확인 모달과 실패 토스트를 렌더링한다.
- `AlertFeature` / `AlertView`: 알림 권한과 로컬 알림 예약만 담당한다.
- `AppFeature`: 탈퇴 성공 delegate를 받아 기존처럼 홈 탭과 마이페이지 상태를 초기화한다.

## 검증 기준

- 로그인 회원은 마이페이지에서 스크롤이나 추가 메뉴 이동 없이 `회원탈퇴`를 볼 수 있다.
- 비회원에게 `회원탈퇴`가 보이지 않는다.
- 취소는 서버 요청을 만들지 않는다.
- 확인은 정확히 한 번 삭제 API를 호출하고, 성공하면 로그아웃된 홈 상태로 이동한다.
- 실패하면 로그인 상태를 유지하고 실패 메시지를 표시한다.
- 알림 화면에는 더 이상 회원탈퇴 UI나 삭제 effect가 없다.
- Figma의 순서·50pt 행 높이·텍스트 무게·회색 탈퇴 텍스트·화살표 부재를 iPhone 실기기에서 확인한다.
- QA는 일회용 계정으로 로그인 → 마이페이지 → 회원탈퇴 → 확인 → 홈 비회원 상태까지 화면 녹화를 남겨 App Review Notes에 첨부한다.
